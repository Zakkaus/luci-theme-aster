# Core LuCI pages present on both 24.10 and 25.12. One entry a line:
#   <path> [modal=<name>] [require=<class>,...]
# A required class must have a sample on the page at every viewport and mode
# (<class>@desktop: on the desktop only; <class>@rows: on the desktop, and on
# a phone whenever the page's tables hold a data row); "button" covers
# button.primary.md and the rest. See checks/lib/gate.mjs.
#
# Not listed, because the lab containers answer 404 (the menu entry's
# dependencies are not met): System > Mount Points (needs block-mount),
# Network > Wireless, Status > Realtime Graphs > Wireless and
# Status > Channel Analysis (no radio), Network > Switch (no switch),
# Status > Firewall (iptables; fw4 uses Status > nftables).
#
# LEDs, Static Routes, Port Forwards, NAT Rules and IP Sets have no rows in
# the lab, and an empty table folds to its caption on a phone: their table
# is required on a phone only while it holds a row (table@rows).
